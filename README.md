## 📌 Project Overview
This is a Machine Learning web app that detects whether a message is Spam or Ham (Not Spam).

---

## 🧠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- NLP (TF-IDF)

---

## ⚙️ Features
- Spam vs Ham classification
- Real-time prediction
- Web UI using Streamlit

---

## 📊 Accuracy
- ~97% using Logistic Regression
